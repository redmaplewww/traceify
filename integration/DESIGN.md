# 研究工作台视觉与行为约束

当前用户认可版本使用深石墨导航、大画布、按需组件库和原文依据前置的详情面板。详细的通用设计技能见[Sleek](../skills/awesome-design-sleek/SKILL.md)。

| 令牌或结构 | 值 |
|---|---|
| 导航 | `#1C293D`，64px宽 |
| 画布 | `#F3F6FA` |
| 主操作 | `#5267D9` |
| 正文 | `#25334A` |
| 次级文字 | `#5F6E85` |
| 工具栏 | 56px高 |
| 节点 | 212×88，圆角13px，16%模块色或类型色填充 |
| 连线 | 常规3px、相邻3.5px、选中4.5px，缩放保持线宽 |
| 模块 | 总主题 → 模块 → 子模块 → 节点，半透明背景和边界 |
| 阅读态字体 | 标题约16px，辅助文字约13px |
| 概览态 | 标题约14px，辅助信息简化 |
| 中等窗口 | 按需详情抽屉 |
| 760px及以下 | 组件、图谱、详情三个可切换面板 |

模块依据与来源分别记录。初次整理旧图采用可撤销布局，之后的手动坐标持续保存。新建空图的节点由用户定位。背景框随成员与子模块的边界变化。

属性草稿按字段记录，切换节点、原文和刷新后可恢复。顶部保存提交当前原文下有效草稿，状态区区分草稿与已保存图谱。旧输入框延迟触发的change事件绑定其原对象。

移植后检查原文双向定位、显式清空保护、过期AI返回、建议关系接受、保存冲突与撤销。使用键盘焦点、颜色与文字共同表达状态，并保持reduced-motion行为。
